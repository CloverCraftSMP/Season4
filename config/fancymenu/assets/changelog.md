## What's new

### Added
- Staff can now go off duty in-game with /lp user <name> parent add offduty, and back on duty with parent remove offduty.
- Hey Wiki, this mod is useful for finding the Minecraft Wiki page for anything in game easier (can be helpful when looking at game mechanics).

### Changed
- Streams reflowing waterways will no longer push players/mobs/boats
- Streams reflowing wands are now disabled
- Increased falling tree max block count
- Poplar signs and trapdoors fixed (patched upstream from drops backport)
- Wool slabs when placed together now drop two slabs instead of one (patched upstream from drops backport)

### Removed
- Moved Dyn Lights to an optional as a number of players have found that they have stutters when using the mod.
